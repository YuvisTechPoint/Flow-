# 🚀 HackQuest × Flow Build Station

Welcome to the **HackQuest × Flow Build Station**, a hands-on Web3 workshop where builders learn, build, and deploy their first **Solidity Smart Contract** on the **Flow EVM Testnet**.  

This README serves as a complete guide for participants to understand the flow, objectives, and submission process for the workshop and hackathon.

---

## 🎯 Objective

The **Flow Build Station** is a 5-hour, in-person workshop where participants:

- Learn the fundamentals of **Web3** and **Flow EVM**
- Build and deploy a **Solidity Smart Contract** on **Flow EVM Testnet**
- Use **AI tools** like ChatGPT, Claude, or Cursor IDE to generate and refine code
- Push their projects to **GitHub** with proper documentation
- Submit their builds to the **$250K Forte Hacks Global Hackathon**
- Compete to be among the **first 100 deployers** and win an exclusive **Flow × HackQuest T-shirt**

---

## 🧩 Workshop Flow

### 1. Learn the Basics of Web3 & Flow
Understand how Flow EVM integrates with the Ethereum ecosystem and explore basic Web3 concepts.

### 2. AI-Powered Vibe Coding
Use AI tools to ideate, generate, and debug your first Solidity contract.  
💡 *Tip:* Each project idea must be unique — no duplicates!

### 3. Deploy on Flow EVM Testnet
1. Claim test tokens from the [Flow Faucet](https://faucet.flow.com/fund-account)
2. Add **Flow EVM Testnet** via [Chainlist (Chain ID: 545)](https://chainlist.org/chain/545)
3. Open [Remix IDE](https://remix.ethereum.org/)
4. Connect MetaMask (configured for Flow EVM Testnet)
5. Deploy your Solidity contract
6. Copy your **contract address** and take a **screenshot** of the deployment

### 4. Push to GitHub
Create a **public repository** and include:
- `Contract.sol` (your Solidity code)
- `README.md` (project overview)
- Deployment **screenshot**
- Contract address and tech stack details

### 5. Submit to HackQuest
Submit your live project to the **[Forte Hacks Global Hackathon](https://www.hackquest.io/hackathons/Forte-Hacks?utm=ccu)**.

✅ Requirements:
- Deployed on Flow EVM Testnet  
- Public GitHub Repo with README  
- Contract Address & Explorer Link  

🎥 *(Optional)*: Add a demo video or tweet tagging `@flow_blockchain` and `@HackQuest_`.

## 💡 Beginner-Friendly Solidity Project Ideas

Here are some easy project ideas you can build and deploy in Remix:

### 🔹 Basics
- **Counter Contract** – Increment/decrement stored value  
- **Simple Storage** – Store and retrieve data  
- **Hello World** – Store and return a greeting message  

### 🔹 Token & NFT
- **ERC20 Token** – Mint your own token  
- **ERC721 NFT Minter** – Mint NFTs with metadata  
- **Token Faucet** – Send tokens to users  

### 🔹 Utility / Game
- **Voting System** – Create and tally proposals  
- **Crowdfunding** – Collect funds if a target is reached  
- **Lottery / Dice Game** – Randomized rewards  
- **Reputation Tracker** – Log achievements on-chain
